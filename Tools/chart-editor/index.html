선택된 효과 편집


그룹 / 효과 목록


그룹은 FX 트랙의 그룹 타임라인에서 구간을 드래그해 만듭니다. 구간 안 노트가 그 그룹이 됩니다.









Special Notes / BPM



특수 노트는 4레인 전체를 채우는 청록색 노트이며 기본 입력은 Space입니다.

입력 성공 여부와 무관하게 속도 효과가 적용됩니다. 성공은 Perfect, 실패는 Perfect 비율을 낮춥니다.

Duration 0은 탭, 양수는 홀드입니다. 홀드는 실제 배속을 0.01 단위로 변경합니다.

BPM Change: 해당 시점을 새 템포 구간의 첫 박자로 사용합니다.

탭의 오른쪽 핸들을 끌면 홀드로 바뀝니다. Tap/Hold 도구 버튼으로도 전환할 수 있습니다.

ARG Chart Encryption



평문 JSON은 편집 원본으로 저장됩니다. Encrypted Release는 현재 차트를 게임 호환 .otchart로 별도 생성합니다.

암호 키는 현재 입력창에서만 사용되며 JSON, undo 기록, 서버 로그에는 저장되지 않습니다. 대소문자를 구분하고 연속 공백은 하나로 정규화합니다.

Auto Coef / Difficulty Curve



노트 밀도를 Gaussian smoothing으로 분석해서 coef 1 노트에 곱할 최종 multiplier를 만듭니다.

저장 시 speedupCoef = baseSpeedupCoef × densityMultiplier × rampMultiplier × manualMultiplier 형태로 기록됩니다.
다시 불러올 때는 baseSpeedupCoef 기준으로 에디터의 coef 0/1 상태를 복원합니다.
